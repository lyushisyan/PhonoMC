Installation
============

Build the solver
----------------

Clone the repository and configure a release build:

.. code-block:: bash

   git clone https://github.com/lyushisyan/PhonoMC.git
   cd PhonoMC
   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DPHONOMC_ENABLE_OPENMP=ON
   cmake --build build -j 4
   OMP_NUM_THREADS=4 ./build/PhonoMC example/input_cross_100nm.toml

The executable is ``build/PhonoMC``. Dependencies are listed in
:doc:`requirements`. Check the CMake output for ``OpenMP enabled``; when the
runtime is unavailable, configuration warns and builds a serial executable.
To request serial operation explicitly, pass ``-DPHONOMC_ENABLE_OPENMP=OFF``.

On macOS with Homebrew, install ``cmake``, ``hdf5``, ``qhull`` and ``libomp``.
Apple Clang may need explicit OpenMP discovery flags:

.. code-block:: bash

   cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
     -DOpenMP_CXX_FLAGS="-Xpreprocessor -fopenmp -I$(brew --prefix libomp)/include" \
     -DOpenMP_CXX_LIB_NAMES=omp \
     -DOpenMP_omp_LIBRARY="$(brew --prefix libomp)/lib/libomp.dylib"

Use a separate build directory when changing compiler or dependency installation.

Local validation
----------------

``BUILD_TESTING`` defaults to ``OFF``. The public source tree builds without
the locally maintained ``tests/`` directory. Developers with that directory
can enable its regression suite:

.. code-block:: bash

   cmake -S . -B build-tests -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
   cmake --build build-tests -j 4
   OMP_NUM_THREADS=4 ctest --test-dir build-tests --output-on-failure --timeout 180

Enabling tests without the local suite produces an explicit configuration
error. Tests and calculations are not downloaded or generated by CMake.
``PHONOMC_TEST_MATERIAL_DATA=ON`` additionally checks bundled material files
when the local suite is present. The executable and tests share the core
library targets and dependency configuration.

Build the documentation
-----------------------

.. code-block:: bash

   python3 -m pip install -r docs/requirements.txt
   python3 -m sphinx -W --keep-going -b html docs/source docs/build/html

Open ``docs/build/html/index.html``. Read the Docs uses ``.readthedocs.yaml``.
Generated documentation is ignored by Git.
