# PhonoMC 截图与审阅指南

配套文件：[中文用户手册](PhonoMC_中文用户手册.md) · [完整输入](user_manual_examples/)

本指南用于你亲自操作、截图和审阅。先完成基础流程 S01—S15，再按实际需要选择材料、界面、热源和器件案例。每一步应先执行、检查输出，再截图；出现错误时保留错误并停在当前步骤排查。

## 1. 第一次从哪里开始

现在只做 S01 即可：打开终端，执行以下三行。

```bash
cd "/Users/sxliu/Library/CloudStorage/OneDrive-个人/Software/GITHUB/PhonoMC"
pwd
ls
```

等列表显示完成，将终端调整到能看清命令、路径和项目文件的大小，再截图。应能看到 `CMakeLists.txt`、`src`、`include`、`material`、`example`、`docs`。

保存为 `S01_project_directory.png`。将截图发回当前聊天后，可以逐张核对并继续下一步；不需要在尚未确认目录时提前运行编译或长计算。

## 2. macOS 如何截图

按 `Command + Shift + 5` 打开系统截图工具，选择“捕捉所选窗口”或“捕捉所选部分”，拖动选区覆盖需要的内容，再点击“捕捉”。可以在“选项”中选择截图保存位置；也可先使用默认位置，随后移动和重命名文件。

快捷截取一块区域可用 `Command + Shift + 4`。如果要截单个窗口，可按该快捷键后再按空格并点击窗口。不同 macOS 设置中的阴影、缩略图显示可能不同，不影响证据内容。

建议新建 `docs/manual_screenshots` 保存截图。你可以在 Finder 中创建，也可以在项目根目录执行：

```bash
mkdir -p docs/manual_screenshots
```

手册不依赖截图提前存在，因此没有放入虚构运行图或损坏的图片占位链接。截图完成后，可将其嵌入你的审阅笔记，例如：

```markdown
![S01 项目目录](manual_screenshots/S01_project_directory.png)
```

截图前适当放大终端字体；只截与当前步骤相关的窗口。长内容分成 a/b 两张，每张保留同一文件名或命令上下文，避免缩小到无法阅读。图像结果应保留完整坐标轴、单位、图例和色条。

## 4. 一轮截图操作的固定节奏

1. 在手册定位当前编号，只执行该步骤的命令。
2. 等输出达到该步骤的截图时机；计算仍在运行时不把它写成已完成。
3. 核对通过标准，不通过就保存错误并记录。
4. 截图、重命名、保存到 `docs/manual_screenshots`。
5. 在审阅笔记写实际命令、结果目录和观察。
6. 需要逐步指导时，将当前截图发回聊天，确认后再继续下一步。

不需要每张截图都含整个桌面；也不要只保留一张无法知道输入来源的彩色云图。原始 PNG、输入文件和结果表同样是复现材料，应和截图一起保留。

## 5. 看到错误怎么办

先保存当前命令和完整错误，例如 `S03_error_hdf5.png`。不要删掉错误输出、随机切换几个参数后只截成功一行。记录修改了什么，再保存修复后的截图，便于手册审阅发现对初学者不清楚的步骤。

需要反馈时给出：当前截图编号、完整命令、第一条关键错误、操作系统和编译/运行环境。HDF5 或几何失败还应提供使用的文件路径及摘要；不必先发送很大的材料文件。

## 6. 审阅时重点看什么

- **可操作性：**每一步是否知道在哪个目录执行、何时算成功、下一步打开哪个文件。
- **术语与单位：**nm/Å、ps/s、W/W·m⁻³、温度/参考温度是否清楚。
- **输入一致性：**正文、配套 TOML 与实际摘要是否一致，文件移动后路径是否仍正确。
- **物理解释：**热流方向、两种热导率、局部加热、Callaway、MMM 的说明是否准确。
- **结果可信度：**是否明确标出教学参数、合成材料、未收敛短例和需要进一步验证的限制。
- **截图质量：**文字可读、上下文充足、图的轴/单位/色条完整。

可以按下列格式记录每条修改意见：

```text
编号：S07 / 手册 §3.2
位置：边界条件说明第几段
实际操作：
观察到的输出：
不清楚或不一致的地方：
建议改法：
关联截图：manual_screenshots/...
处理状态：待核对 / 已修改 / 已复查
```
