# FinFET／三层 GAAFET 对比计算包

2026-10-16。采用 52×24×50 nm 外包围盒、52×24×20 nm 衬底、相同源漏和
120 nm² 总沟道截面积。FinFET 截面 6×20 nm；GAAFET 为三层 10×4 nm 纳米片。
完整尺寸见 `geometry/model.json`。这是规定晶格热源的硅结构比较，尚未包含栅极、
氧化层、电子输运或电热自洽，因此不应称为完整工艺器件预测。

## 固定的比较条件

- 衬底四侧仅 Z<20 nm 部分周期连接，X/Y 周期分别 52/24 nm。
- 衬底底面和源漏顶面均为 300 K 热浴；面积分别为 1248 和总计 480 nm²。
- 其他暴露表面使用 η=1 nm 的粗糙反射；不等同于严格完全漫反射。
- RTA 和非线性 Callaway 均使用局域温度率、同一保守边界实现及同一份 Si 25³ 材料表。
- 基准功率为每个完整器件 1 μW；GAAFET 每层分配 1/3 μW。
- 热源在 X=36–42 nm，中心 39 nm、σ=1.5 nm，高斯分布；对真实硅截面归一化，空隙不加热。
- 网格为 1×1×0.5 nm³；活动单元 86400，加热单元 1440；dt=0.05 ps。

`validation/geometry_*.json` 检查所有 36 个扫描输入的实际 C++ 几何、周期平移、
热浴面积及分层功率；`validation/model_pairing.json` 核验 RTA／Callaway 输入仅改变
碰撞算子与输出路径。`files_sha256.json` 固定源代码、材料、几何、输入与启动脚本。

## 分阶段计算

| 阶段 | 数量 | 设置 | 用途 |
|---|---:|---|---|
| smoke | 8 | 两器件×两模型×0/1 μW；0.5M 载体，5 步 | 真实材料初始化、零源平衡、源记账 |
| pilot | 4 | 两器件×两模型；1 μW，10M 载体，1000 步 | 50 ps 试算，测耗时、内存和统计行为 |
| production | 36 | 两器件×两模型×0.2/1/2 μW×3 种子；10M，40000 步 | 暂定 2 ns 扫描输入，尚未获收敛验证 |

三档功率是待试算确认的候选值。3 个种子为 12345、12346、12347；两种模型使用
相同种子有助于控制设置，但不能假定碰撞后随机轨迹仍逐粒子配对。
完整清单在 `cases.json`。输入准备完成不表示计算完成。

## 运行与部署

需要 CMake≥3.20、C++17、HDF5 C++、OpenMP，以及 Python≥3.11 和 NumPy。
先在服务器激活现有可用的编译／Python 环境，再在计算包根目录运行：

```sh
bash scripts/build.sh
python3 scripts/run_case.py smoke --all --binary build/PhonoMC
python3 scripts/run_case.py pilot --index 0 --binary build/PhonoMC
```

pilot 的索引为 0–3。Slurm 示例为 `scripts/smoke.slurm`、`pilot.slurm`、
`production.slurm`，使用 normal 分区／wanggang 账户、28 核、96 GiB、24 小时；
这些是待试算调整的申请值，数组并发限制为 1，不会自动提交。

必须通过 `run_case.py` 启动。它在输入所在目录运行程序，并核验实际加载的材料路径，
避免程序优先搜索当前目录时误读仓库中的另一份 Si 材料。
每次运行保存输入和二进制哈希、时间、日志及能量检查结果，不覆盖已有轨迹。
服务器重新编译后的二进制必须重新通过 8 项 smoke。
部署包不带本地 smoke 轨迹和门槛文件；直接复制整个本地目录会因已有记录而拒绝重跑。

`production_readiness.json` 默认为 false。它需要在试算和科学检查完成后依据证据更新，
而不是为绕过检查直接改为 true。短测通过仅允许启动试算。

## 后续科学检查与输出

1. 延长基准轨迹，比较后半窗和末四分之一窗的峰值／热源加权温升、分层温升与热阻；
   结合相关时间和独立种子判断稳态。先以均值变化 <1%、统计不确定度 <2% 为候选目标，
   最终容差应小于论文中需要分辨的 RTA／Callaway 差异。
2. 在代表性输入上检查 dt 减半、网格细化和载体数增加。细化网格时保持足够的每单元载体数，
   根据服务器试算估计内存后安排；2 ns 和 10M 并不是已收敛参数。
3. 做小温升极限检查，连接旧薄膜的固定参考温度线性 Callaway 与器件的局域温度非线性 Callaway。
4. 1 μW 试算完成后确认 0.2/1/2 μW 是否覆盖合适温升区间，且不越出 50–800 K 材料表。
5. 若论文要展示底部与源／漏分别导出的功率，需要增加逐热浴累计能量输出。
   当前稀疏记录的总热浴单步通量不足以可靠计算完整的分热浴功率比例。

正式扫描所有输入每 10 ps 输出温度；仅四个 1 μW、种子 12345 输入输出全场矢量热流。
计划数据量约 12–22 GiB，仅为估计，需用服务器试算校准，不含延长轨迹或文件系统副本。
主图建议包含统一色标温升场、三层温升、ΔT/P 热阻、功率依赖及 RTA／Callaway 差异与误差条。
比较热点时应同时给出固定空间区域平均值，避免直接把有噪声的单网格最高温当作稳定峰值。
