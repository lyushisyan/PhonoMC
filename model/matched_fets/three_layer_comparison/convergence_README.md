## 接受标准

时间稳定首先看固定热源加权温升、通道及分层均温；候选标准为末段窗口均值变化 <1%，
但最终统计与离散化误差必须显著小于拟解释的 RTA／Callaway 差异。
采用独立种子误差条，并考虑时间相关性；单格最高温和相邻时间块不能单独作为通过依据。
时间步、粒子数、网格分别检查，所有对照使用相同物理总时长和功率。
逐热浴功率分配仍需要额外的累计能量诊断，现有稀疏输出不能直接给出可靠分流比例。

`cases.json` 保存逐算例成本外推，`plan.json` 给出执行顺序；`files_sha256.json` 固定关键文件。
本包没有提交原来的 36 项功率扫描，也没有生成新的收敛结果。
